# shamanchi-phyto-live — PHYTOTAB

Магазин PHYTOTAB на платформе Shamanchi: каталог 52 товаров с ценами и фото, маркетплейс-флоу
каталог → карточка → корзина → оформление → заказ, раздел «Знания врача», отзывы с Яндекс.Карт,
инфо-страницы (доставка, оплата, возврат, FAQ, сертификаты, контакты, о бренде, о враче,
юридические документы). Next.js static export, GitHub Pages.

До решения о запуске сайт не регистрируется на доменах бренда и не показывается третьим лицам
как действующий магазин.

## Что внутри

- **Каталог 52 товаров** — фитосборы, грибы в капсулах и порошках, фитохитодезы, витамины
  и добавки, наборы по системе Евгения Козлова. Данные — `data/products.json`,
  структура витрин — `data/catalog.json`.
- **Разделы** — 15 разделов каталога, подборки «Скидки недели», «Популярное», «Наборы
  по системе», «Грибы», «Фитосборы», «Фитохитодезы», «Подборки от Евгения».
- **Фильтры и поиск** — раздел, формат, цена, сортировка, поиск по названию/составу.
- **Карточка товара** — фото, цена, наличие, состав, способ применения, похожие товары,
  категории-теги.
- **Корзина** — количество, удаление, промокод, пересчёт, бесплатная доставка СДЭК от порога.
- **Оформление** — контакты → доставка (СДЭК / курьер по Москве / Почта / самовывоз) → оплата;
  обязательный чекбокс согласия с офертой и политикой ПД.
- **Заказ** — номер заказа, статус «менеджер пришлёт ссылку на оплату», сохранение в браузере.
- **Мои заказы** — история заказов (localStorage) и повтор заказа.
- **Избранное** — сердце на карточках и странице товара, отдельная страница, бейдж в шапке.
- **Контент** — «Знания врача» (7 статей с обложками и фото), отзывы (6, вкладки по темам),
  15 инфо-страниц, включая «О компании» (история бренда, статистика, фото) и 6 юридических
  документов с реквизитами.
- **Живой фон** — tsParticles (пыльца + листья в hero), на мобильном урезан, при
  `prefers-reduced-motion` — статичен.
- **Формулировки** — безопасные: «поддерживает», «способствует», «традиционно применяется».

## Технологии

Next.js 15 (App Router) + Tailwind CSS, статический экспорт на GitHub Pages
(`output: "export"`, `basePath: "/shamanchi-phyto-live"`). Без бэкенда: товары в JSON,
корзина и история заказов в localStorage. Точки интеграции — ниже.

## Команды

```bash
npm ci
npm run build            # статический экспорт в ./out
npm run test:acceptance  # приёмочный сценарий по ./out (нужен Chrome/Edge, см. tests/acceptance.mjs)
npm run dev              # локальная разработка: http://localhost:3000/shamanchi-phyto-live
```

Локальный предпросмотр статики:

```bash
node scripts/serve-static.mjs   # поднимает ./out на http://127.0.0.1:4173/shamanchi-phyto-live/
```

## Публикация (GitHub Pages)

Workflow `.github/workflows/deploy.yml` собирает `npm ci && npm run build` и публикует `./out`
через официальные actions Pages. После пуша в `main` сайт доступен по адресу:

<https://shamanchi.github.io/shamanchi-phyto-live/>

`basePath` читается из `NEXT_PUBLIC_BASE_PATH`, дефолт — `/shamanchi-phyto-live`
(см. `next.config.mjs`).

## Точки подключения (для этапа запуска)

- **Платёжный шлюз** — финальный шаг `components/checkout/CheckoutView.jsx` и
  `components/ShopContext.jsx` (`placeOrder`): сейчас заказ уходит в статус
  «менеджер пришлёт ссылку на оплату». Готово под ЮKassa / Prodamus / Robokassa —
  точка чистая, интерфейс и флоу не меняются.
- **Промокоды** — `lib/site.js`, словарь `SHOP.promo` (коды проверки механики: `PHYTOTAB10`,
  `PHYTOTAB15`); после запуска заменить на реальные акции.
- **Доставка** — `lib/site.js` (`SHOP.delivery`) и `lib/shop.js` (`deliveryCost`, пороги
  бесплатной доставки по федеральным округам).
- **Личный кабинет** — `components/ShopContext.jsx` (`orders` в localStorage);
  после запуска — синхронизация с бэкендом.
- **SEO** — товарные запросы уже в мета-описаниях страниц; полная SEO-настройка
  (sitemap, структурированные данные на товары) — после решения о запуске.
